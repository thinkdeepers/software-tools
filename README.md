## 软件简介

**TodoThings** 是一款 Windows 本地桌面待办工具，数据保存在本机（SQLite / sql.js），不依赖云端账号。适合需要轻量、可置顶、可侧边停靠的日常任务管理。

安装包与便携版位于本分支目录：

- [`install安装包/TodoThings.exe`](./install安装包/TodoThings.exe) — 便携版，双击即可运行
- [`install安装包/TodoThings 安装版.exe`](./install安装包/TodoThings%20安装版.exe) — NSIS 安装包（可改安装目录、创建快捷方式）

## 主要功能

1. **窗口置顶**：可将窗口始终置于其他窗口之上；支持自由调整大小，方便贴在桌面一侧使用。
2. **侧边停靠**：在「置顶 → 侧边停靠」中开启。闲置或关闭主界面后，窗口收拢为屏幕边缘一条半透明细线；鼠标移到细线处即可展开。支持左 / 右 / 上 / 下四边，并按当前显示器定位（多屏下不会跑到邻屏）。开启后不在任务栏显示按钮，通过系统托盘或边缘细线唤出。
3. **快速新建**：底部输入框可直接新建待办。
4. **计划分类**：按「计划」管理待办；可切换某一计划，也可一键查看「所有计划」。支持新建、重命名、删除计划。
5. **主题**：白色 / 黑色 / 多彩色三种主题。
6. **子待办**：任务可创建子任务，形成树状结构。
7. **优先级**：紧急（红）/ 重要（橙）/ 普通（蓝）/ 较低（灰），列表按优先级排序。
8. **日期与提醒**：可为待办设置日期；勾选「提醒」后，到期会弹出系统通知。
9. **已完成显示**：可在「编辑」菜单中选择显示或不显示已完成待办。
10. **字体**：支持字号与字体族切换（微软雅黑、幼圆、仿宋、楷体等）。
11. **托盘常驻**：关闭窗口默认隐藏到系统托盘（开启侧边停靠时则缩到边缘细线）；托盘可打开窗口、新建待办 / 计划、切换置顶与侧边停靠、退出。

## 使用说明

- 关闭窗口：未开启侧边停靠时 → 隐藏到托盘；开启侧边停靠时 → 缩到边缘半透明细线，应用继续在托盘运行。
- 从托盘「打开 TodoThings」或双击托盘图标可恢复主界面。
- 真正退出请使用托盘菜单「退出」。
- 左侧（计划菜单）管理计划，主区域编辑任务树。
- 日期可清空；仅填写日期并勾选「提醒」后才会系统通知。

## 开发

```bash
npm install
npm run dev
```

## 打包 Windows 安装包

```bash
npm run pack
```

输出到 `release/`，最终发布文件请放入本分支 `install安装包/`：

| 文件 | 说明 |
|------|------|
| `TodoThings.exe` | 便携版（免安装） |
| `TodoThings 安装版.exe` | NSIS 安装包 |

数据保存在本机用户目录（SQLite，经 sql.js）。
