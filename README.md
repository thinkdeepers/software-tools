# 护眼卫士 EyeCare

一款跨平台全局护眼软件，通过全屏透明遮罩实现滤蓝光、亮度调节和休息提醒。

## 功能特性

| 功能 | 说明 |
|------|------|
| **全局护眼滤镜** | 全屏暖色遮罩覆盖所有显示器，鼠标穿透，不影响操作 |
| **色温调节** | 0–100 可调，数值越高暖色越强（滤蓝光越多） |
| **亮度调节** | 0–100 可调，降低屏幕刺眼感 |
| **预设模式** | 健康 / 办公 / 阅读 / 夜间 / 影院，一键切换 |
| **休息提醒** | 定时提醒休息，支持全屏倒计时界面 |
| **定时护眼** | 仅在指定时段自动启用 |
| **系统托盘** | 后台运行，托盘图标快速开关和切换模式 |
| **开机自启** | 可选登录后自动启动 |

## 系统要求

- **Linux**：X11 或 Wayland，Python 3.10+，PyQt6
- **Windows 10/11**：无需安装 Python，直接运行 EXE

## 快速开始

### Linux

```bash
chmod +x run.sh
./run.sh
```

## Windows（EXE）

安装包位于 **`release/`** 文件夹：

```
release/
└── 护眼卫士.exe
```

下载后双击 `护眼卫士.exe` 即可运行。

### 自行打包 Windows EXE

在 Windows 电脑上：

```bat
build-windows.bat
```

输出：`dist\eyecare.exe`（发布时复制为 `release\护眼卫士.exe`）

或通过 GitHub Actions 自动构建：仓库 → Actions → Build Windows EXE → Run workflow

### 安装到系统（可选）

```bash
chmod +x install.sh
./install.sh
```

安装后可在应用菜单中找到「护眼卫士」，或使用命令 `eye-care` 启动。

## 使用说明

1. **启动程序** — 运行 `./run.sh`，托盘出现眼睛图标
2. **调节护眼** — 双击托盘图标打开设置，调节色温和亮度
3. **快速切换** — 右键托盘 →「快速切换模式」选择预设
4. **开关护眼** — 右键托盘 →「开启/关闭护眼」
5. **休息提醒** — 在「休息提醒」标签页设置工作/休息时长

## 预设模式说明

| 模式 | 色温 | 亮度 | 适用场景 |
|------|------|------|----------|
| 健康 | 25 | 85 | 日常使用，轻度护眼 |
| 办公 | 45 | 75 | 长时间办公 |
| 阅读 | 60 | 65 | 阅读文档 |
| 夜间 | 85 | 45 | 夜间使用，强滤蓝光 |
| 影院 | 70 | 55 | 观影娱乐 |

配置保存在 `~/.config/eye-care/config.json`，可手动编辑或备份。

## 技术原理

### Windows

通过 **伽马曲线（Gamma Ramp）** 在显卡输出层调节色温与亮度，作用于整个屏幕的所有内容，包括：

- 右键菜单、任务栏弹出项
- Alt+Tab / Win+Tab 预览窗口
- 开始菜单、通知中心
- 所有应用程序窗口

若显示器不支持伽马调节（如部分 HDR 模式），自动回退到全屏遮罩方案。

### Linux

在每个显示器上创建全屏、置顶、鼠标穿透的透明遮罩窗口，通过暖色与暗色叠加实现护眼效果。
