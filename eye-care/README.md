# 护眼卫士 EyeCare

一款 Linux 全局护眼软件，功能参考 [CareUEyes](https://www.care-eyes.com/)，通过全屏透明遮罩实现滤蓝光、亮度调节和休息提醒。

## 功能特性

| 功能 | 说明 |
|------|------|
| **全局护眼滤镜** | 全屏暖色遮罩覆盖所有显示器，鼠标穿透，不影响操作 |
| **色温调节** | 0–100 可调，数值越高暖色越强（滤蓝光越多） |
| **亮度调节** | 0–100 可调，降低屏幕刺眼感 |
| **预设模式** | 健康 / 办公 / 阅读 / 夜间 / 影院，一键切换 |
| **休息提醒** | 定时提醒休息，支持全屏倒计时界面 |
| **定时护眼** | 仅在指定时段自动启用 |
| **系统托盘** | 后台运行，托盘图标快速开关和切换模式 |
| **开机自启** | 可选登录后自动启动 |

## 系统要求

- **Linux**：X11 或 Wayland，Python 3.10+，PyQt6
- **Windows 10/11**：无需安装 Python，直接运行 EXE

## 快速开始

### Linux

```bash
cd eye-care
chmod +x run.sh
./run.sh
```

### Windows（EXE）

1. 下载 `护眼卫士.exe`（见下方构建说明或 GitHub Actions 产物）
2. 双击运行，程序常驻系统托盘（右下角隐藏图标区域）
3. **右键**托盘图标 → 设置 / 切换模式 / **退出程序**
4. 左键单击仅显示状态提示，双击打开设置

> 程序无任务栏图标，关闭设置窗口不会退出，只能通过托盘右键「退出程序」。

### 自行打包 Windows EXE

在 Windows 电脑上：

```bat
cd eye-care
build-windows.bat
```

输出：`dist\护眼卫士.exe`

或通过 GitHub Actions 自动构建：仓库 → Actions → Build Windows EXE → Run workflow

### 安装到系统（可选）

```bash
chmod +x install.sh
./install.sh
```

安装后可在应用菜单中找到「护眼卫士」，或使用命令 `eye-care` 启动。

## 使用说明

1. **启动程序** — 运行 `./run.sh`，托盘出现眼睛图标
2. **调节护眼** — 双击托盘图标打开设置，调节色温和亮度
3. **快速切换** — 右键托盘 →「快速切换模式」选择预设
4. **开关护眼** — 右键托盘 →「开启/关闭护眼」
5. **休息提醒** — 在「休息提醒」标签页设置工作/休息时长

## 预设模式参考

| 模式 | 色温 | 亮度 | 适用场景 |
|------|------|------|----------|
| 健康 | 25 | 85 | 日常使用，轻度护眼 |
| 办公 | 45 | 75 | 长时间办公 |
| 阅读 | 60 | 65 | 阅读文档 |
| 夜间 | 85 | 45 | 夜间使用，强滤蓝光 |
| 影院 | 70 | 55 | 观影娱乐 |

## 配置文件

配置保存在 `~/.config/eye-care/config.json`，可手动编辑或备份。

## 项目结构

```

└── src/
    ├── main.py         # 主程序入口
    ├── overlay.py      # 全局护眼遮罩
    ├── break_timer.py  # 休息提醒
    ├── settings_window.py  # 设置面板
    ├── tray.py         # 系统托盘
    ├── config.py       # 配置管理
    └── autostart.py    # 开机自启
```

## 技术原理

程序在每个显示器上创建一个全屏、置顶、鼠标穿透的透明窗口，通过叠加暖色（模拟降低色温/滤蓝光）和暗色（模拟降低亮度）实现护眼效果，类似 CareUEyes 的屏幕滤镜方案。
